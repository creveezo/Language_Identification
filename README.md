# Character N-gram Language Identification

A lightweight language identification system based on character n-gram frequency profiles.

The project explores how character-level statistical patterns can be used to identify the language of a text. It implements a frequency-based baseline and examines how the choice of n-gram length and training corpus size affects language identification.

## Overview

Language identification is a text classification task in which the goal is to determine the language of a given text.

This project implements a character n-gram approach. The system builds language profiles from a multilingual corpus and compares the n-gram distribution of an input text with the profiles of known languages.

The current implementation supports *18 languages* and returns a ranked list of the three most likely languages.

### Data and Dictionary Availability

The `dicts/` directory does not contain dictionaries generated from the 500K, 1M, and full-text corpora because these files exceed GitHub's file size limits. They can be regenerated using `diff_corpora_creating.py`.

## Method

The system follows a frequency-based approach:

1. **Text preprocessing** — prepares the training texts for n-gram extraction.
2. **N-gram extraction** — generates sequences of consecutive characters for different n-gram lengths (from 1 to 6).
3. **Language profiling** — calculates the frequency distribution of n-grams for each language.
4. **Text classification** — compares the n-gram profile of an input text against the stored language profiles.
5. **Ranking** — returns the three languages with the highest similarity scores.

The model uses character-level features rather than word-level features. This allows it to capture spelling patterns and common character sequences without requiring tokenization or language-specific morphological analysis.

## Dataset

The initial corpus consists of Bible translations in 18 languages, based on the [Taxi1500 dataset](https://github.com/cisnlp/Taxi1500/tree/main/Taxi1500-c_v1.0).

The project also explores the effect of training corpus size by working with different amounts of text, ranging from short samples to larger collections.

**Note:** Since the initial corpus consists of religious texts, its representativeness of general-purpose language use is limited. Evaluation on texts from other domains is an important next step.

## Experiments

The project explores several factors that may influence language identification:

- **N-gram length:** comparing character n-grams of different sizes (1–6).
- **Training corpus size:** investigating how the amount of training text affects language profiles.
- **Input text:** examining how the amount of available text influences the classification output.

## Current Limitations

- The model relies on frequency-based character n-gram profiles and does not use a supervised machine learning classifier.
- The training corpus is limited to Bible translations, which may introduce domain-specific patterns.
- The current output is a ranking of candidate languages, not a calibrated probability distribution.
- A systematic evaluation on an independent test set is still needed.

## Future Work

Planned improvements include:

- Building a reproducible train/test evaluation pipeline.
- Measuring accuracy, macro-F1, per-language F1, and top-3 accuracy.
- Analyzing the effect of input text length and n-gram order.
- Testing robustness to spelling errors, punctuation changes, and diacritic removal.
- Evaluating the model on texts from domains beyond religious literature.
- Comparing the frequency-based baseline with machine learning approaches such as Multinomial Naive Bayes and character-level TF-IDF with Logistic Regression.
